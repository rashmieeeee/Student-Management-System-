# Student Database Management System (Python + SQLite)

A command-line app with CRUD operations on student records.

## Run
Requires Python 3.8+ only. No packages to install.

    python main.py

## Files
- main.py                - menu, input validation, printing
- database.py            - connection + table/index creation
- student_operations.py  - all SQL queries (CRUD + statistics)

The database file `students.db` is created automatically on first run.
